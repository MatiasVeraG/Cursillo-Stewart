# Carpeta de Simulacros

Esta carpeta contiene los archivos PDF de simulacros que se mostrarán en la página `simulacros.html`.

## 📂 Cómo agregar simulacros:

1. Ve al panel de administración (`admin.html`)
2. Selecciona la pestaña "📝 Simulacros"
3. Completa el formulario:
   - Nombre del simulacro
   - Selecciona uno o varios archivos PDF
4. Click en "➕ Agregar Simulacro"
5. **Los archivos se descargarán automáticamente**
6. **Coloca esos archivos PDF en esta carpeta** (`documents/simulacros/`)

## ⚠️ IMPORTANTE:

- Los archivos deben estar **exactamente** en esta carpeta
- **NO cambies el nombre** de los archivos después de agregarlos en el admin
- Si cambias el nombre, el link en la página pública dejará de funcionar

## 🗑️ Para eliminar:

1. Elimina la referencia desde el panel admin
2. **También elimina manualmente** el archivo PDF de esta carpeta

## 🌐 En el hosting:

Asegúrate de subir esta carpeta con todos los archivos PDF al mismo nivel de tu proyecto.

La ruta debe ser: `documents/simulacros/nombre-del-archivo.pdf`
